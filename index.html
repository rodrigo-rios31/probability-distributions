Cómo usar la calculadora

  1. Elige la distribución tocando la tarjeta superior. Hay 15 distribuciones continuas y 7 discretas.
  2. Escribe los parámetros o muévelos con el deslizador. Los campos aceptan expresiones como 1/6, sqrt(2) o 2.5e-3; el botón ± cambia el signo.
  3. Elige el tipo de cálculo:
    • Cola izquierda: P(X ≤ x) o P(X < x)
    • Cola derecha: P(X ≥ x) o P(X > x)
    • Intervalo: P(x₁ ≤ X ≤ x₂)
    • Dos colas: P(X ≤ x₁) + P(X ≥ x₂)
    • Inversa: dada una probabilidad p encuentra el valor x (percentiles, valores críticos).
  4. Arrastra los puntos rojos de la gráfica para cambiar x en tiempo real, o haz clic/toca en cualquier punto de la gráfica.
  5. Cambia entre Densidad (área bajo la curva = probabilidad) y Acumulada (F(x) = P(X ≤ x)).
  6. En Fórmulas encontrarás la función de densidad, la acumulada, la media, la varianza y usos de cada distribución. En Tabla puedes generar y exportar tablas de probabilidad.

Sobre < y ≤

En las distribuciones continuas P(X = x) = 0, así que P(X < x) = P(X ≤ x). En las discretas sí importa: P(X < 5) = P(X ≤ 4).

Precisión

Todos los cálculos usan algoritmos numéricos de doble precisión (Cody para la normal, fracciones continuas para las funciones gamma y beta incompletas, Loader para binomial y Poisson). Las probabilidades de las colas se calculan directamente, sin restar de 1, por lo que valores tan pequeños como 10⁻³⁰⁰ son exactos. Verificado contra referencias de 50 dígitos con error relativo menor a 10⁻¹¹.
